# sistem-panen-aryo 
Sistem Pencatatan Hasil Panen Digital

Deskripsi Singkat
Program sederhana berbasis Python untuk menghitung total hasil panen berdasarkan data berat hasil panen. Program juga dilengkapi fitur perhitungan diskon untuk menghitung potongan harga dan harga akhir setelah diskon.

Cara Menjalankan Program
1. Pastikan Python sudah terinstal di komputer.
2. Buka folder proyek sistem-panen menggunakan VS Code atau terminal.
3. Buka terminal pada folder tersebut.
4. Jalankan program dengan perintah: py Panen.py
5. Program akan menampilkan total hasil panen, total harga, besar diskon, potongan harga, dan harga akhir.
